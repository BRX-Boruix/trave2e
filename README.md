# trave2e

BORUIX 的验收程序：验证目录遍历权限——无执行权限的目录，其下文件不可达。

[English](README.en.md)

由 shell 的内建命令派生运行，不单独使用。

## 测什么

程序先以属主身份准备两份对照目录：一份带执行权限（0755），一份不带（0700），两份目录下的
文件都是 0644。然后降级为普通用户身份，依次检查：

- 普通用户可以读取带执行权限目录下的文件——对照组成立
- 普通用户读取无执行权限目录下的同一份文件被拒绝，错误码是权限不足
- 两次检查发生在同一时刻、同一身份，唯一变量是目录的执行位

判据：**无执行权限的目录，其下文件即使 0644 也不可达**。

程序最后还主动尝试提升自己的身份，并期望被拒绝——身份只能降低不能升高。

## 退出码

- `0`——全部通过
- 非零——失败项编号，对应输出中 `FAIL(n)` 的位置；编号区间区分属主侧与降级侧


```
└── src/
    └── main.rs   # 对照夹具的建立与降级检查
```
